无需格式化 U 盘，不碰系统设置。选好整合包，一键写入 U 盘或直接安装到电脑，随插随玩。

使用文档

U 盘部署

不格式化、不清盘。只在 U 盘建立 jftw_Go_Assets 目录，每个整合包一个文件夹，根目录自动生成快捷方式与启动脚本。

在线直装

没有 U 盘也能玩。jftw Go Direct 在线下载后解压到指定目录，一键启动，小白也能轻松搞定。

多语言

内置 简体中文 / 繁體中文 / English 语言包，随时切换；界面字体使用内嵌思源黑体，清爽统一。

安全可控

本地运行，数据只留在你的设备。下载支持 SHA256 校验，文件完整可验证，写入前还有二次确认。

U 盘上的目录结构U:\
├─ jftw_Go_Assets\
│   └─ version\
│       ├─ <整合包 A>      ← 每个整合包独立文件夹
│       │   └─ start1.exe
│       └─ <整合包 B>\
│           └─ start1.exe
├─ jftw Go.lnk            ← 快捷方式
└─ jftw Go.bat            ← 启动脚本
